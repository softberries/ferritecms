# What the documentation claims, and how it was checked

Every claim in `site/content/` is listed here with what it was checked against. "Run"
means the command was run on 2026-10-31 with a debug build of branch `m4-3b-site-1`
(`m4-3` at 9930a25, with the `docs` and `business` themes, plus these pages), in a scratch
folder, unless the row says otherwise. Paths are relative to the repository root; line numbers are those of that
build. The pages name the data folder `./mysite`; the runs used `./site` in a scratch
folder (the name changes nothing). A row marked **not run** or **not verified** says why.

Part 1 (Task 7) covers the getting-started pages and the guides. Part 2 (Task 8) covers
the developer, operations and reference pages: its runs were made on 2026-10-31 with a
debug build of branch `m4-3b-site-2` (`m4-3` at 9ba8f74 plus these pages), in a scratch
folder holding a site `./mysite` made with `init --url http://localhost:8095`, a user
`me`, `seed demo` and `serve` on `127.0.0.1:8095`, so the API runs used that origin where
the pages show `http://localhost:8080`. Postgres runs used a local Postgres 17 at
`localhost:54329` with throwaway schemas (dropped afterwards). Line numbers in part 2 are
those of 9ba8f74.
