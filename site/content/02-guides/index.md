# Guides

Task-oriented guides for running a site day to day.

- [AI assistants (MCP)](08-ai-assistants.md): connect Claude, ChatGPT, Claude Code,
  Cursor or VS Code and run the site by asking: write and publish, organise media and
  menus, moderate comments, check the site's health. Coming in the next release (0.2.0); build from source today
  ([Install → Build from source](../01-getting-started/01-install.md#build-from-source)).
- [Writing and publishing](01-writing.md): the editor, publishing and scheduling,
  autosave, revisions and previews.
- [Media](02-media.md): uploads, image sizes, featured and inline images.
- [Content types, taxonomies and menus](03-content-types.md): model your content and
  your navigation.
- [Themes](04-themes.md): the built-in themes, their settings, and installing your own.
- [Plugins](05-plugins.md): installing a plugin, the permission report, settings and the
  example plugins.
- [Import from WordPress](06-import-wordpress.md): move a WordPress site over, with
  redirects from the old addresses.
- [Import Markdown](07-import-markdown.md): turn a folder of Markdown files into pages.
