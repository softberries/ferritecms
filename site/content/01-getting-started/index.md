# Getting started

These pages take you from nothing to a running site with an admin account.

1. [Install](01-install.md): download a signed release binary or the Docker image, or
   build the `ferrite` binary from source.
2. [Your first site](02-first-site.md): create a data folder, add an account, start the
   server and sign in to the admin.
3. [Concepts](03-concepts.md): content types, items, terms, menus, themes and plugins, and
   how they fit together.

When the site runs, the [guides](../02-guides/index.md) cover the daily work.
