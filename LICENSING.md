## What the AGPL means for you

You can use, modify and run FerriteCMS freely, including in production and for your
clients' sites. If you modify FerriteCMS and let other people interact with that modified
version over a network (for example as a hosted service), the AGPL requires you to offer
those users the complete source code of your modified version under the same license.

## Plugins and themes

A plugin or theme you write is yours to license as you like, closed source included, as
long as it only uses the plugin interface (the WIT files in `wit/`) or the theme interface.
You may also copy the plugin SDK, the WIT files, the example plugins and the starter
themes into it. See [LICENSE-EXCEPTION.md](LICENSE-EXCEPTION.md) for the exact terms.

## Commercial license

A commercial license removes the AGPL obligations, including the source-offering
requirement for modified versions run as a network service.
