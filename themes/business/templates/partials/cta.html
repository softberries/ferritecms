{#- The call-to-action button from the settings `cta_label` and `cta_url`. Expects `cta_class` (extra classes). Nothing when either setting is empty, or when the URL names a scheme other than http, https, mailto or tel (no `javascript:` link). The scheme is the part before the first `:` when no `/`, `?` or `#` comes before it, so a path such as `/book/?at=10:00` is kept. Both values are auto-escaped, so a quote in the URL cannot leave the attribute. -#} {%- set cta_label = site.settings.cta_label | trim if site.settings.cta_label is string else "" %} {%- set cta_url = site.settings.cta_url | trim if site.settings.cta_url is string else "" %} {%- set head = cta_url | split(":") | list | first if ":" in cta_url else "" %} {%- set has_scheme = ":" in cta_url and "/" not in head and "?" not in head and "#" not in head %} {%- set scheme_ok = not has_scheme or (head | lower) in ["http", "https", "mailto", "tel"] %} {%- if cta_label and cta_url and scheme_ok %} {{ cta_label }} {%- endif %}
