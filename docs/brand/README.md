# FerriteCMS brand files

The logo: a hexagon of ember and steel bands around an "F". Vector files, drawn on a
128 × 128 grid; the words are Montserrat Bold and Medium (SIL OFL 1.1) converted to
outlines, so no font is needed to show them.

| File | Use |
|---|---|
| `ferrite-mark.svg` | the mark with a soft light from the top left |
| `ferrite-mark-flat.svg` | the mark in flat colours: favicons and small sizes (the admin's `favicon.svg`) |
| `ferrite-logo-horizontal-light.svg` / `-dark.svg` | mark and words side by side, for light / dark backgrounds |
| `ferrite-logo-stacked-light.svg` / `-dark.svg` | mark above the words, for light / dark backgrounds |
| `apple-touch-icon.png` | 180 × 180 home screen icon |
| `social-preview.png` | 1280 × 640 link preview; upload it under the repository's Settings → Social preview |

Colours: ember `#d2652c`, steel `#3f78a8`; text `#1f2329` on light backgrounds and
`#eceef1` on dark ones.
